## 🚀 Como clonar e compilar

1. 📋 Clone o repositório:
   ```bash
   git clone https://github.com/JoaoKSS/Constest-0.git
   cd Constest 0
   ```

2. ⚙️ Compile e execute:
   ```bash
   git checkout ContestA
   g++ -std=c++17 contest-0-A-joao-kennedy-souza-soares.cpp -o contestA
   ./contestA < input.txt
   ```

## ⚙️ Dependências

- 🛠️ Compilador C++ compatível com C++17 (g++, clang++, MSVC)
